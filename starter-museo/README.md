# Starter — Museo Web de la Evolución Gráfica

Esta base reduce trabajo de configuración, pero no contiene respuestas ni la solución de la misión.

## Ruta rápida

1. Abre `index.html` en un navegador.
2. Reemplaza todos los marcadores `PENDIENTE` con investigación y evidencia propia.
3. Duplica las estructuras de ejemplo hasta cumplir cinco hitos y tres experimentos.
4. Guarda imágenes optimizadas dentro de `assets/` y agrega texto alternativo y crédito.
5. Personaliza la identidad visual: la hoja incluida es solo un punto de partida.
6. Prueba el sitio a ancho de teléfono y computadora, con teclado y en una ventana privada.
7. Publica el repositorio en GitHub e impórtalo en Vercel.

## No entregues hasta comprobar

- [ ] Siete secciones obligatorias completas.
- [ ] Cinco hitos con limitación, cambio, impacto, ejemplo, imagen y fuente.
- [ ] Tres experimentos con predicción, datos y conclusión.
- [ ] Función RGB → HSV probada y explicada.
- [ ] Diez términos del glosario en palabras propias.
- [ ] Créditos y fuentes verificables.
- [ ] Sin contraseñas, tokens ni archivos `.env`.
